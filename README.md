# Pais de Jauja
by *Diego Morales Castillo*
## Overview
*Pais the Jauja* is an environment for live music collaboration between human performers and AI driven agents capable of generating audio-visual material by the same means as their human counterparts.

The software itself includes a collection of audio and video synthesizers with maping capabilities for comercial and DIY MIDI devices, as well as the required tools to train models based on different classical machine learning and deep learning algorithms that can later be used to spawn agents capable of comunnicating through MIDI with the same symthesizers as the user.
Aditionally the the software has recording and live-straming capabilities with multiple output formats.
